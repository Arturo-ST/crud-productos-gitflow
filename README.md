# CRUD de Productos — Git Flow

Proyecto académico de Programación III que demuestra un CRUD funcional y el uso de ramas y Pull Requests.

## Tecnologías
- Python 3 (biblioteca estándar)
- SQLite
- HTML, CSS y JavaScript

## Ejecución
```bash
python app.py
```
Abra `http://localhost:8000` en el navegador.

## Funcionalidades
- Registrar, listar, editar y eliminar productos.
- Validar nombre, precio y cantidad.
- Persistencia de productos en SQLite.

## Flujo de ramas
`main` (entrega), `dev` (desarrollo), `qa` (revisión) y cinco ramas `feature/`.
